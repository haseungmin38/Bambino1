# 밤비노 (BAMBINO) 쇼핑몰 데모

- `index.html`: 화면 구조
- `style.css`: 반응형 디자인
- `script.js`: 상품/회원 등급 데이터와 화면 기능
- `img/`: 히어로 배너 4장 및 상품 그림 8장(SVG)

## 실행
`index.html`을 브라우저에서 열면 됩니다. GitHub Pages에서도 별도 빌드 없이 동작합니다.

## 데모 주의
수업용 프런트엔드 시연이며 실제 결제·주류 판매·배송은 하지 않습니다. 회원 비밀번호는 데모 편의를 위해 localStorage에 저장되므로 실제 비밀번호를 사용하지 마세요. 실서비스에서는 서버 인증, 비밀번호 해시, DB, 성인 인증, 법률 검토가 필요합니다.
